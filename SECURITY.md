# Security reports

[Русский](#русский)

Use GitHub's private vulnerability reporting form in the repository's Security tab when it is enabled. Include the affected version, the profile, the impact, and a minimal synthetic reproduction. Share any confidential inputs through the private report.

## Русский

Когда в репозитории включены приватные сообщения об уязвимостях, используй форму во вкладке Security. Укажи версию, профиль, последствия и минимальный синтетический пример. Конфиденциальные материалы прикладывай только к приватному сообщению.
