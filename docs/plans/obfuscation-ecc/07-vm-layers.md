# Этап 07 Измеренный вклад вложенности VM

Общие правила: [WORKFLOW.md](WORKFLOW.md). Статус: [STATUS.md](STATUS.md). Основание: [исследование](../../research/obfuscation-research.ru.md). Идентификаторы источников ниже раскрыты в исследовании.

## Основание и результат

Исследование: R7; C09/C11. Второй уровень основной VM — lookup выбора handler, тогда как Lab depths 3/4 относятся к фиксированной арифметике. Результат — измерение каждого дополнительного уровня на одинаковой задаче, без обещания эффекта от числа уровней.

Зависимости: 05–06 COMPLETE. Область: `src/vm/inner.rs`, строго необходимые части dispatch/runtime, отдельные `lab/layers.rs` и evaluation. Сначала абляции существующих уровней; новую универсальную рекурсивную VM не строить без результата этого сравнения и отдельного дизайна.

## Шаги разработки

1. Записать семантику уровня для каждого профиля: какая задача исполняется и какое состояние проходит между уровнями.
2. Добавить исследовательский обход/включение существующего дополнительного уровня при сохранении полезного результата. Не представлять несуществующие конфигурации как готовую матрицу.
3. Проверить переходы, возврат, границы таблиц и состояние. Для Lab сделать отдельные контроли глубин; не смешивать их статистику с native.
4. Выполнить одинаковые анализы по реальному времени/памяти, а не только по ограничению числа инструкций внутреннего анализатора.
5. Сравнить восстановление и transfer после удаления простых обёрток; учесть dispatch, расшифрование, startup, runtime, память и размер.
6. Оценить, остаётся ли вклад уровня после нормализации и относительно уже принятой композиции 06.
7. Зафиксировать ADOPT/REJECT/INCONCLUSIVE для каждого профиля. Если доказана лишь большая длина трассы, записать отсутствие подтверждённого выигрыша стойкости.

## Приёмка и review

- Контрольные варианты выполняют одну задачу; остальные настройки сохранены или явно учтены.
- Снятие слоя не подменено удалением полезной работы и не меняет oracle.
- Review проверяет корректность абляции, границы уровней и смешение понятий глубины native/Lab.
- ADOPT требует дополнительного измеренного вклада после нормализации и transfer; исчерпание 256 шагов не удовлетворяет критерию.
- Результат не экстраполируется на произвольную рекурсивную виртуализацию.

Цена: дополнительные переходы и состояние. Отказ от слоя по результатам сравнения — допустимое инженерное решение.
