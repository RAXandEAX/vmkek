# Выполнение roadmap обфускации через ECC

Пакет переводит [исследование](../../research/obfuscation-research.ru.md) в восемь последовательных задач. Для каждого этапа порядок один: **feature dev → Rust review → orch fix при замечаниях → повторное Rust review**. Цикл исправления и повторного review продолжается до закрытия всех подтверждённых замечаний и выполнения критериев этапа.

Сейчас подготовлены задания. Разработка, ECC review и сравнительные эксперименты по этим заданиям ещё не выполнены. Их статус хранится в [STATUS.md](STATUS.md).

## Как запускать

1. Подготовить рабочую копию с исходниками vmkek и этим каталогом вместе с исследованием. Текущий Windows-каталог содержит исследовательские документы; наличие `.git` само по себе не означает наличие исходников. Перед первым запуском проверить `Cargo.toml`, `src/`, `crates/`, `evaluation/` и локальные инструкции.
2. Прочитать [правила выполнения](WORKFLOW.md). В целевой среде проверить регистрацию `/feature-dev`, `/rust-review`, `/orch-fix-defect`. Это команды агента, а не команды PowerShell/Bash.
3. Открыть файл этапа и передать агенту первую команду из раздела «Запуск». Дождаться отчёта разработки. Затем запустить review в отдельном контексте с доступом к тому же дереву и артефактам.
4. Если review нашло замечания, запустить команду fix. После каждого fix обязательно запустить повторное review. Повторять эти две команды столько раз, сколько потребуется.
5. Переходить дальше только после `COMPLETE` в карточке этапа. При невозможности выполнить обязательную проверку записать `BLOCKED` и конкретную причину; отсутствие инструмента не превращать в чистое review.

Шаблоны ролей: [разработка](prompts/feature-dev.md), [review](prompts/rust-review.md), [исправление](prompts/orch-fix.md), [повторное review](prompts/rereview.md). Каждая команда в файле этапа передаёт конкретный номер и путь; шаблоны не нужно редактировать для каждого запуска.

Команды здесь подготовлены для будущего выполнения. Пакет не устанавливает ECC, не запускает агентов и не содержит автоматического commit/push/merge.
