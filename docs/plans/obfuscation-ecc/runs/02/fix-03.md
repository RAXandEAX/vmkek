# Исправления O02-F003 и O02-F004

Драйвер абляции возвращает успех только при наличии восьми вариантов с успешным процессом, двумя корректными controls и двадцатью уникальными успешными строками fixture/seed на каждый вариант. Частичный manifest сохраняется в summary с количеством строк, статусами и ошибками проверки. Отсутствующие или повреждённые результаты дают ненулевой выход.

Все текстовые замены требуют ровно одного совпадения до записи файла. Изменение balanced-flatten seam воспроизвело дефект на исходном драйвере, теперь вызывает ошибку и оставляет файл нетронутым. Тесты проверяют ошибки, пропуски, дубли строк и controls при успешном коде дочернего процесса.

Проверено 49 тестов Python с доступной user bus, все прошли. Без bus тот же запуск имел 9 пропущенных интеграционных subtests. `git diff --check` прошёл. Строки mock error в тестовом stdout не являются результатами benchmark.
