# Нативная ELF абляция

Команда `python3 -B evaluation/research_native_ablation.py --repository /home/rax/vmkek-obfuscation-ecc --output /home/rax/.cache/codex-evaluation/ecc-02/native-ablation-01 --signer <test-signer> --pin <test-pin>` создала отдельный scratch clone из `4cd330d`, применила принятый patch этапа 01 и исследовательское инструментирование из `instrumentation.patch`. Инструментирование включается только в scratch сборке через `VMKEK_ECC_ABLATION`. Основной код протектора не получает этот переключатель. Версия сборки Rust 1.95.0, release, offline, WSL2. Хэши, время сборки и полные результаты — `summary.json`; полные бинарники и oracle-результаты находятся в `/home/rax/.cache/codex-evaluation/ecc-02/native-ablation-01/`.

Фикстуры `affine_xor` и `counter` принадлежат корпусу этапа 01. Для каждого варианта использованы 10 seed 0x401–0x40a, все 160 защищённых артефактов и 16 исходных контролей прошли существующий oracle по 6 public cases. Фикстуры, профиль и seeds фиксированы; пропуск прохода меняет расход RNG, а OS entropy authenticated-профиля меняет байты. Эксперимент оценивает состав pipeline, а не независимый эффект при неизменных случайных решениях.

10 прогонов на каждый из 160 защищённых образов запущены перемешанно с одинаковым публичным входом. Таблица показывает медиану 20 отдельных медиан по двум функциям и десяти seed. Это время полного запуска процесса с входом и проверкой результата, оно включает startup и стоимость harness. Время конкретной защищённой функции отдельно не измерено. Объединение двух функций дано для ориентира, пофункционные данные — `timing.json`.

`rewrite` отключает MBA и маскирование констант совместно. `flatten` здесь означает сбалансированный authenticated ELF dispatcher. Исследовательское отключение stamps и отдельных правил MBA/констант не реализовано. Не проводилась оценка semantic recovery, нормализации нативных артефактов и memory peak. Измеренная стоимость не является измерением стойкости. Все результаты относятся только к перечисленным вариантам и среде.
