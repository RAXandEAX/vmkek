## Закрытие

**O02-F001 · CLOSED.** В `src/obf/hard.rs` исходный комментарий прямо описывает известный вход. Поле `assumption` допускает указание границы утверждения. Crypto остаётся Red с `level=None`. Семь тестов `obf::hard::` независимо прошли с Rust 1.95.0. Предыдущие измерения бюджета и 72 IR вариантов относятся к неизменённым частям Rust diff.

## O02-F002 LOW · Определение Red расходится с новой Crypto строкой

`src/obf/hard.rs:51,68,83`. Документация `ChannelColor` связывает Red только с невыполнением проверки. Документация `anchor` говорит, что Red указывает причину её отсутствия. Новая Crypto строка имеет Red и ссылается на выполненный тест `known_preimage_executes_and_s1_does_not_fold`. Код и строки доказательств здесь верно описывают отсутствие доказанной стойкости, а комментарии дают более узкое и противоречивое определение.

Критерий закрытия — Red означает, что свойство канала не подтверждено. Anchor указывает релевантный тест или причину недостатка свидетельств. Оставить значения строки и тестовое поведение прежними.

## Независимая нормализация

Повторена команда `clang-18 -O1 -S -emit-llvm normalization-fixture.c -o - | diff -u normalization-fixture.ll -` из каталога отчёта с Ubuntu Clang 18.1.3. Код выхода 0, содержимое идентично. Прямой предикат известного входа свёрнут в `65117` (0xfe5d), обе пары возвращают исходный операнд. Это вручную выписанные C выражения с одной парой умножения. Они подтверждают исходный контроль, но сами по себе не измеряют восстановление преобразованного бинарника или архитектурные flags.
