# Этап 06 — решение по композиции

**NOT_APPLICABLE** для композиции новых проходов. После проверки этапов 03–05 нет кандидата с решением ADOPT.

| Этап | Решение | Проверенное основание |
| --- | --- | --- |
| 03 | REJECT | Clang свёл все 20 вариантов арифметической композиции к исходному телу. [Ревью 03](../03/review-02.md) |
| 04 | REJECT | Три варианта кодирования аккумулятора дали одинаковое LLVM-тело на C-фикстуре. [Ревью 04](../04/review-02.md) |
| 05 | INCONCLUSIVE | Отдельная регистровая модель подтвердила корректность и число dispatch. Вклад в стойкость нативной VM остаётся неизмеренным. [Ревью 05](../05/review-01.md) |

Этап 02 даёт опорную серию из 160 проверенных ELF-сборок с удалением отдельных проходов. Фактический вклад нового порядка, взаимодействие преобразований и перенос анализа требуют отдельного эксперимента. [Нативная серия 02](../02/native-ablation-01/README.md), [ревью 02](../02/review-04.md).

Пункт приёмки этапа 06 разрешает NOT_APPLICABLE при отсутствии принятых кандидатов. Штатная последовательность остаётся контрольной. К эксперименту композиции вернуться после принятия подходящего кандидата и фиксации сравниваемых вариантов, oracle и протокола переноса. [План этапа 06](../../06-control-flow.md)
