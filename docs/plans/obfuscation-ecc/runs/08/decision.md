# Решение этапа 08

Выполнена ограниченная функциональная квалификация на зафиксированных owned-фикстурах Windows x64 и Linux ELF WSL2. Принят исследовательский стенд и уточнение claims. Новых защитных преобразований с решением ADOPT нет.

Базовое сопоставление и affine fresh/transfer выполнены для текущего production CLI. Общий native recovery для других семейств, полная матрица PE/ELF и физический Linux остаются непроверенными. Разделы платформенных границ и принятых решений содержатся в [отчёте](implementation.md). Экспериментальный статус не означает установленную стойкость.
